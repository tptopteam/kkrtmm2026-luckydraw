# เขาค้อวิ่งทะลุหมอก มาราธอน 2026 - ระบบสุ่มผู้โชคดี & ตรวจสอบรายชื่อนักวิ่ง

ระบบสุ่มผู้โชคดีและตรวจสอบรายชื่อนักวิ่ง (Lucky Draw & Runner Directory) อัปเดตรายชื่อนักวิ่งครบถ้วน 1,531 คน ตรงตาม Runlah Official และ Google Sheet

## 🚀 วิธีการเอาขึ้น GitHub Pages (100% ฟรี)

### วิธีที่ 1: อัปโหลดโฟลเดอร์ `dist` ผ่าน GitHub Web (ไม่ต้องติดตั้ง Git)
1. สร้าง Repository ใหม่บน [GitHub.com](https://github.com/new) ตั้งชื่อเช่น `kkrtmm2026-luckydraw` (ตั้งค่าเป็น **Public**)
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจากในโฟลเดอร์ `dist/` ขึ้นไปที่ Repository
3. ไปที่เมนู **Settings** > **Pages**
4. ในช่อง **Source** ให้เลือก Branch `main` (หรือ `master`) แล้วกด **Save**
5. รอ 1-2 นาที คุณจะได้ URL เว็บไซต์ฟรีทันที เช่น: `https://<ชื่อยูสเซอร์ของคุณ>.github.io/kkrtmm2026-luckydraw/`

---

### วิธีที่ 2: ใช้ Git Command Line
```bash
git init

git commit -m "Initial commit for Khao Kho Lucky Draw"
git branch -M main
git remote add origin https://github.com/<your-username>/kkrtmm2026-luckydraw.git
git push -u origin main
```
